Writing a page

Pages are written in Markdown. Leave a blank line between paragraphs.

Headings

Start a line with # for a heading, and add more for smaller ones:

# Heading
## Smaller heading

Lists

Start each line with - or * for a bulleted list, or a number for a numbered one:

- Eggs
- Milk

1. Buy groceries
2. Check mail

Links to other pages

Put a page's name in double square brackets to link to it. Add | and some text to change what the link says. [[home]] links to your site's front page.

See [[Recipes]].
See [[Grocery list|my list]].
Back to [[home]].

If the page doesn't exist yet, following the link lets you create it.

Links to other sites

Put the link text in square brackets and the address in parentheses right after it:

Visit [Jottit](https://jottit.pub/).

Contact

For help with Jottit, please email feedback@jottit.pub. Please include the URL of your Jottit site in your email.
